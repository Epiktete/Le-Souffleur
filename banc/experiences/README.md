# Les expériences

Un dossier par expérience, nommé `AAAA-MM-JJ-sujet/`. Chacun contient :

- `NOTES.md` : la date, la question, le dispositif (contes, âges, chaîne utilisée,
  commit, modèle qui joue), les résultats et ce qu'on en retient ;
- `histoires/` : chaque spectacle produit, tel que le parent le lirait. En tête,
  un commentaire donne la date, le cas, la chaîne et l'emplacement des données
  brutes.

Les données brutes du relais (chaque prompt, chaque réponse) restent dans
`banc/relais/`, où elles se rejouent. Ce dossier-ci garde ce qu'on relit : les
histoires et les notes.
